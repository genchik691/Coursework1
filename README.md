# Анализ банковских транзакций

## 📋 Описание проекта

Приложение для анализа банковских транзакций из Excel-файлов. Программа генерирует JSON-данные для веб-страниц, формирует отчеты, предоставляет сервисы для анализа кешбэка и инвестиций.

### Основные возможности

- 📊 **Главная страница** - приветствие, информация по картам, топ-5 транзакций, курсы валют и акции
- 📈 **Страница событий** - аналитика расходов и поступлений, топ-7 категорий
- 💰 **Кешбэк анализ** - расчет потенциального кешбэка по категориям
- 🏦 **Инвесткопилка** - расчет накоплений через округление трат
- 🔍 **Поиск** - простой поиск, поиск по телефонам, поиск переводов физлицам
- 📑 **Отчеты** - траты по категориям, дням недели, рабочим/выходным дням

## 🚀 Установка и запуск

### Требования

- Python 3.13 или выше
- Poetry (рекомендуется) или pip

```bash

# Или через pip

Запуск приложения
